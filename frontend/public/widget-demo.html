External Client Website Demo

This HTML page simulates an external customer website embedding the standalone BotForge AI chat widget via a single <script> tag.

📋 Embed Snippet

To embed the chatbot, clients simply paste this single snippet into their website's HTML before the closing </body> tag:

<script src="http://localhost:8000/widget.js" data-public-key="YOUR_PUBLIC_KEY" async></script>
